# Reviews

Required before CODE_REVIEW → MERGED or SA CHANGES_REQUESTED.

UX/UI reviews of FE work live in `docs/design/ux/reviews/TASK-###-review-NN.md`
(copy `templates/ux-review.md`). They run before SA review when `requires_uxui` is not `false`.
